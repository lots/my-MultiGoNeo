Preferences

Board

100%

The canvas renderer uses CSS themes instead of a bitmap board path. Brightness is applied to the board surface.

Stones

Bitmap stone paths and random stone images are not applicable to the procedural canvas stones. The selected board theme supplies the stone palette.

Markers & Numbers

Other

Window-side / tree-position choices and custom panel background colours from MultiGo are omitted because the FigDesk shell owns those panels. The result-title option updates both the window title and file label.

Traverse

ms

Sound is generated with Web Audio (best effort). Fast-forward step counts and “resume last position” are not implemented yet.

Edit

BIG5 auto-detection, new-file templates and automatic branch merging are not implemented.
